# Kedai Kopi Lens — Landing Page

Website statis HTML, CSS, dan JavaScript dengan kategori menu Coffee, Non Coffee, dan Makanan.

## Menjalankan
Buka `index.html` di browser, atau jalankan Live Server dari VS Code.

## Sesuaikan sebelum dipublikasikan
- Ubah contoh nama menu dan harga di `index.html`.
- Ganti query Google Maps pada iframe di bagian `#location` dengan alamat/link embed lokasi kedai yang tepat.
- Ganti foto Unsplash dengan foto asli kedai/menu bila tersedia.
- Periksa ulang semua URL gambar sebelum deploy.
